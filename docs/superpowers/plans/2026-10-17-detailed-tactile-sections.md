# Detailed Tactile Sections Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** New paintings get specific sections (eyes, lips, earring, not just "her face") and 10x10 grids
that a hand can recognize (a bust, not a solid triangle).

**Architecture:** `paintings.fetch_painting` splits its single Gemini call in two. Call 1 sees the whole
painting and returns 5-10 sections in tour order (whole subject first, then its features), with boxes and
descriptions but no grids. Code crops each box (padded, made square) with Pillow; then one Gemini call per
section, run in parallel, sees only that crop and designs a tactile grid for it (outlines and key
features, guided by example grids). Sections whose drawing fails are dropped.

**Tech Stack:** Python 3, `google-genai` (`gemini-3-flash-preview`), Pillow, `concurrent.futures`.

**Spec:** No separate spec file. The design was agreed in chat on 2026-10-17 and is summarized in
Goal/Architecture above. Problem source: teammate feedback ("Jesus is a triangle"; "you feel the face's
circle, not the eyes").

```python
def fix_grid(grid):
    """Force exactly 10x10 of 0/1, whatever the model returned (numbers or '#'/'.' strings)."""
    rows = [[1 if v in (1, "1", "#") else 0 for v in list(row)[:10]] for row in list(grid)[:10]]
    rows = [r + [0] * (10 - len(r)) for r in rows]
    return rows + [[0] * 10 for _ in range(10 - len(rows))]

def crop_square(img, bbox, pad=0.15):
    """Cut bbox out of img, padded and widened to a square so shapes aren't stretched on the board."""
    w, h = img.size
    x0, y0, x1, y1 = bbox[0] * w, bbox[1] * h, bbox[2] * w, bbox[3] * h
    side = max(x1 - x0, y1 - y0) * (1 + 2 * pad)
    cx, cy = (x0 + x1) / 2, (y0 + y1) / 2
    return img.crop([round(cx - side / 2), round(cy - side / 2), round(cx + side / 2), round(cy + side / 2)])

def jpeg(img):
    buf = BytesIO()
    img.convert("RGB").save(buf, "JPEG", quality=90)
    return buf.getvalue()
```

Replace the whole `analyze` function with:

```python
def ask_gemini(image_bytes, mime, prompt, thinking):
    client = genai.Client()  # reads GEMINI_API_KEY
    resp = client.models.generate_content(
        model="gemini-3-flash-preview",
        contents=[types.Part.from_bytes(data=image_bytes, mime_type=mime), prompt],
        config=types.GenerateContentConfig(response_mime_type="application/json",
                                           thinking_config=types.ThinkingConfig(thinking_level=thinking)))
    return json.loads(resp.text)

def analyze(image_bytes, mime, title, summary):
    """Call 1: the parts of the painting, in tour order, without grids."""
    data = ask_gemini(image_bytes, mime, SECTIONS_PROMPT.format(title=title, summary=summary), "low")
    if isinstance(data, list):  # sometimes it returns [{...}] or the bare sections list
        data = data[0] if data and "sections" in data[0] else {"sections": data}
    return data

def draw(crop_bytes, title, s):
    """Call 2, once per section: design a grid from just that crop. None if it fails."""
    try:
        data = ask_gemini(crop_bytes, "image/jpeg", GRID_PROMPT.format(
            name=s["name"], title=title, description=s["description"]), "medium")
        if isinstance(data, list):
            data = data[0]
        return fix_grid(data["grid"])
    except Exception as e:  # drop this section, keep the tour
        print(f"draw failed for {s['name']!r}: {e!r}")
        return None
```
